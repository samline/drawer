`@samline/drawer` exposes a `createDrawer` factory plus a small registry of imperative helpers, renders DOM directly with a vanilla host, ships a typed IIFE bundle for `<script>` tags, and keeps every transition and animation in CSS. It is the only runtime entrypoint since v3.0.0 — no React, Vue, or Svelte wrapper, no virtual DOM, just one factory and a focused method surface.

## Why @samline/drawer?

- **Vanilla-first** — Works with native HTML pages, embedded scripts, static sites, and server-rendered templates.
- **Two entrypoints** — Import the ESM factory for bundlers, or drop a single `<script>` for the browser global (`window.Drawer`).
- **Data-attribute driven** — Every visual state is a CSS rule reading a `data-*` attribute. Theme by overriding CSS variables, no inline JS styles.
- **Observable controllers** — `subscribe(listener)` fires immediately with the current snapshot, then on every state change. Pair with Redux, Zustand, Pinia, or your own view layer.
- **Same-id updates** — Reusing a drawer `id` updates the existing instance in place. The DOM never grows past the visible stack.
- **Snap points + scale background** — Snap-point math, drag-to-dismiss, and page-shell scaling are all built in. See the [Examples](/drawer/reference/examples/) for end-to-end patterns.
- **Zero runtime dependencies** — Tiny footprint, ESM + CJS bundles, ships its own types, and a IIFE for `<script>` tags.
