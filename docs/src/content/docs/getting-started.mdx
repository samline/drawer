## Requirements

Use Node.js 20 or newer for package tooling and a modern browser with ES2020, Pointer Events and pointer capture. Modal isolation uses `inert` and `aria-hidden`; test any older browsers in your support matrix. HTML / CDN needs no Node.js or bundler at runtime. The website's own build-tool requirements are separate from the published package.

## One instance, one controller

Start with createDrawer(), keep its controller and use setOpen(), update() and destroy(). You do not need registry helpers, a namespace module or headless state for this first integration. An id is optional; omitted ids are independent, and explicit ids must be unique.

## Your first working drawer

Choose a loading mode, then save the HTML, CSS and JavaScript files together. **Package / ESM** works with an HTML-entry bundler such as Vite. **HTML / CDN** opens directly in a browser with an internet connection. Both use the same public API and panel styles.

The package stylesheet supplies motion and the handle. The example stylesheet supplies panel position, dimensions, colors and focus styles. Keep that import order. Drawer owns dismissal, focus management and scroll locking; your application owns accessible content and instance cleanup.
