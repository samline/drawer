## Choose your integration

Use `@samline/drawer` for named ESM or CommonJS imports. Use `@samline/drawer/browser` for the module namespace. Plain HTML loads the separate IIFE and stylesheet; it exposes `window.Drawer`. DOM integrations run in the browser. The headless `createDrawerController` can model state without the DOM.

Read [entrypoints and module formats](reference/entrypoints/) for the loading terminology and [lifecycle and state](guides/lifecycle-and-state/) for instance ownership.

## Styling and accessibility

The runtime stylesheet supplies motion and handle behavior. Your application defines panel position, dimensions, colors, accessible content and visible focus. Modal focus management and scroll locking stay in Drawer. See [Accessibility and focus](guides/accessibility-and-focus/).
